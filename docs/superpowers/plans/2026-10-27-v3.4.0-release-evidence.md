## Choices and limits

- Exclusive lock waits approximately five seconds; never time-evicts. Abandoned lock recovery is manual after stopping all writers. Atomic semantics require local filesystem support.
- JSONC and complex TOML refuse unchanged/manual merge; no runtime dependency added for a lossy parser.
- ZadLoop plugin fields verified in installed runtime README, but stable active-profile automatic merge target unproven. Manual export only; no invented skill folder.
- Status is diagnostic-only; explicit guide generation or enabled safe refresh creates index.
- App-tree exception requires .git; package metadata is insufficient because applications ship it.
- No actual client UI/model obedience testing. Protocol fixtures do not establish UI compatibility.
- Independent reader review failed to return findings. Author source review found/fixed additional regressions; lead independent review still expected.
